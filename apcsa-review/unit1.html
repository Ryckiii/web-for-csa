1.1 第一个 Java 程序 · print vs println#

每个 Java 程序的最小骨架都长一个样：Class 名首字母大写、{} 必须成对、 method 声明行如 public static void main(String[] args) { 行尾不加分号， 而普通语句必须以 ; 结尾，否则直接无法编译。

输出只有两条命令，区别就一个字：System.out.println(...) 打印后换行； System.out.print(...) 不换行，下一句接着屁股后面写。

沙盘 A · 拼出第一个程序
⚠️ 坑点 注释（// 行注释、/* 块注释 */）不会被 compiler 翻译成机器语言—— 它们只给人类看。调试题里「把注释当代码」是常见障眼法。

Quiz 1-2-11

下面三行代码的输出是？

System.out.print("Java is "); System.out.println("fun "); System.out.print("and cool!");
  • Java is fun and cool!（全部挤在一行）
  • Java is fun ⏎
    and cool!（fun 后面换行）
  • 三行分别输出 Java is / fun / and cool!
  • 编译错误

print 不换行，所以 "Java is " 和 "fun " 连起来； println("fun ") 结束后换行 ⏎，最后的 print("and cool!") 出现在下一行行首。

1.2 Variables and Data Types#

Variable 是「与某个内存位置关联的名字」，里面装着会变的值，比如游戏里的 int score = 0;。Java 的 type 分两大阵营： primitive（原始类型）——variable 里直接存值本身，AP 只考下面前三位； reference type（引用类型）——variable 里存的是 object 的「地址」，代表就是 String。

int　32 bits
整数：分数、人数、年份　int score = 4;
double　64 bits
小数：价格、温度、平均分　double price = 23.25;
boolean　≥ 1 bit
是非：只有 true / false　boolean won = false;
String　reference type
一段文字　String name = "Sam";（存的是指向字符序列的"地址"）

把值放进 variable 分两步：declaration（声明）按 type 分配内存，如 int age;； initialization（初始化）第一次塞值，如 age = 23;。 注意 double health = 8.5; 这种「declaration + 赋值」合体也算 initialization。 命名规范：有意义、小写开头的 camelCase、大小写敏感、绝不能加引号。

⚠️ 坑点 Assignment 方向永远是 variable = expression;：4 = score; 直接编译错误。 Type 也得对得上：int temperature = 70.5; 拒绝编译；boolean sunny = 1; 更不行，Java 的真假只有 true / false。

Quiz 1-3-20

要存储 GPA（如 3.85）和 numStudents（如 28），最合适的声明组合是？

  • int GPA; int numStudents;
  • double GPA; int numStudents;
  • double GPA; double numStudents;
  • String GPA; int numStudents;

GPA 带小数 → double；人数是整数 → int。 用 int 存 GPA 会丢掉小数（3.85 → 3）；人数用 double 虽然能编译，但 type 语义不准确，考试不认。

1.3 Expressions and Assignment · Integer Division 与 %#

Assignment statement 的结构是 variable = expression;——先算右边，再装进左边， 如 score = (10 * points) + 5;。Arithmetic operator（算术运算符）有 + - * / %，比较用 ==（相等）、!=（不等）； 注意 = 是赋值、== 才是比较。 Precedence（优先级）：* / % 先于 + -，括号最大。

这节有一个让无数考生翻车的细节：integer division 直接丢掉小数部分（truncation），不是四舍五入—— 2 / 3 是 0 不是 0.67；想保住小数， expression 里至少一个操作数必须是 double（比如写一个 2.0）。 另一个小怪癖：x % y 当 x < y 时结果就是 x 自己（2 % 3 = 2）。

沙盘 C · Expression 实验室 ⭐
⚠️ 坑点 判断 expression 的 type：从下往上、逐格看两边的 type。只要某一格出现了 double， 这一格往上全部按小数算；全是 int 的那一格，除法 / 取模都按整数规则 truncation。这就是做题口诀。

Quiz 1-4-11

3 % 8 = ?

  • 2
  • 3
  • 0
  • 编译错误

3 ÷ 8 = 0 余 3。当 x < y 时，x % y 的结果就是 x 自己——商是 0，整个 x 都变成余数留下来。

Quiz 1-4-3

执行完下面的代码后，x、y、z 的值各是多少？

int x = 0, y = 1, z = 2; x = y; y = y * 2; z = 3;
  • x = 0, y = 2, z = 3
  • x = 1, y = 2, z = 3
  • x = 1, y = 4, z = 2
  • x = 2, y = 2, z = 3

赋值是「拷贝值」，不是绑定：x = y; 后 x 变成 1（y 后来的变化与 x 无关）。 然后 y = 1 × 2 = 2，z 被直接改写为 3。追踪 variable 就一行一行往下抄当前值。

1.4 Compound Assignment Operators#

「运算 + 赋值」可以一步写完（shortcut）： x = x + 1; ≡ x += 1; ≡ x++;（++/-- 步长固定为 1）； 同理 -= *= /= %=。展开规则永远成立：x op= v ≡ x = x op v， 所以 compound assignment 也一样逃不出 integer division 的手掌心。

沙盘 D · 步进：score 是怎么一步步变成 0 的
int score = 0; System.out.println(score); score++; System.out.println(score); score *= 2; System.out.println(score); int penalty = 5; score -= penalty / 2; System.out.println(score);
点 ▶ 开始逐行执行，也可以按 ← → 方向键
⚠️ 坑点 score -= penalty / 2; 展开是 score = score - (penalty / 2)： 右边 expression 先完整求值，而 penalty / 2 两边都是 int → 5 / 2 = 2。考试里这就是最终答案是 0 而不是 -0.5 的原因。

Quiz 1-5-3

执行完下面的代码后，x、y、z 的值？

int x = 3, y = 5, z = 2; x = z * 2; y = y / 2; z++;
  • x = 4, y = 2.5, z = 3
  • x = 6, y = 2, z = 3
  • x = 4, y = 2, z = 3
  • x = 4, y = 2, z = 2

x = 2 × 2 = 4；y 是 int，5 / 2 走 integer division = 2（不是 2.5！）； z++; 让 z = 3。凡是「追踪值」的题，先把每个 variable 的 type 圈出来。

1.5 Casting and Ranges of Variables#

Casting（类型转换）写法是 (目标 type) 值， 结果的 type 就是你写的那个目标 type。它的成名时刻是救回 integer division 的精度—— 但前提是 cast 要写在运算发生之前：(double)(5000 / 110) 救不回来， (double) 5000 / 110 才行。四舍五入的标准技巧：正数 (int)(number + 0.5)，负数 (int)(negNumber - 0.5)。

沙盘 E · Casting 对照台：两条流水线
⚠️ 坑点 判断正误：Java 的 integer division 不会自动四舍五入（Quiz 1-6-5 直接考这句）； casting 的结果也不一定是 double（1-6-6）——结果的 type 永远等于你写的目标 type， 转不了会直接报错。char 与 int 可以互转，所以 (char) 65 能得到 'A'。

Quiz 1-6-7

三个 int 成绩的总和是 total，下面哪个 expression 能算出正确的平均值（保留小数）？

  • total / 3
  • (double)(total / 3)
  • (double) total / 3
  • (int)(total / 3.0)

A：两边都是 int，先 integer division 丢精度。B：括号里除完才 cast，丢掉的找不回来 （板书：(double)(7 / 2) → 3.0，不是 3.5）。 C ✓：先把 total 变成 double，除法按小数算。D：虽然 3.0 救回了小数运算， 但最后 (int) 又把小数砍掉了。

Quiz 1-6-5 · 判断

对还是错：Java 的 integer division 会自动把结果四舍五入。

  • true
  • false

integer division 永远 truncation（直接向零靠拢）：7 / 2 = 3、 -7 / 2 = -3。想手动实现四舍五入：正数 (int)(number + 0.5)、负数 (int)(number − 0.5)。
