先戳一题试试手感#

热身题

下面这行 Java 代码的输出是什么？

System.out.println(2 / 3);
  • 0.6666666666666666
  • 0
  • 0.67
  • 编译错误

两个操作数都是 int，Java 走整数除法：2 ÷ 3 = 0 余 2，商 0，小数部分直接丢掉（不是四舍五入！）。想保留小数，至少让一个操作数成为 double，比如 2.0 / 3。这是 Unit 1 §1.3 全站最大的坑。

答错没关系，继续点；题卡会记住你的「首试」成绩并写进本地进度。正式题目都在 Unit 1、Unit 2 与 Unit 3 里。
