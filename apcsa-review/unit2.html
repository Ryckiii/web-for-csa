2.1 Class 是蓝图，Object 是实例#

Class 是 object 的蓝图（blueprint）：它正式定义了一类事物的 attributes（属性，即 instance variable）和 behaviors（行为，即 method）。 Object 是 class 的具体实例（instance）——带着确定的属性值。 就像课件里的类比：饼干模具是 class，压出来的每一块饼干是 object；"akash" 是 Human 这个 class 的一个 object。

class
定义了一种新数据类型——blueprint 本身
object
class 的 specific instance，带确定的 attributes
attributes / instance variables
定义 object knows about itself（name、age…）
behaviors / methods
定义 object 能做什么（walk()、showInformation()…）
沙盘 A · 饼干模具：每 new 一次，object +1
⚠️ 坑点 Instance variable 必须写在所有 method 外面（class 体里直接声明）。 在课件 Calculator 示例里，如果 int num1; 写进了某个 method，其他 method 就找不到它了——那是 local variable，不是 instance variable。

Quiz 2-1-3 · 选全部正确项

课堂原题是「定义配对」。下面四条说法里，配对正确的是哪两条？

  • class = 创建 object 的 blueprint，定义了一种新的数据类型
  • 一个 class 最多只能 new 出 10 个 object
  • methods 定义「object 知道自己什么」
  • object = class 的具体 instance，带着确定的 attribute 值

methods 定义的是 object能做什么；"知道自己什么"是 attributes / instance variables 的活儿。object 数量没有任何上限——想 new 多少都行（Quiz 2-1-4 马上考这句）。

2.2 Constructor · Signature · Stack & Heap#

Constructor 是特殊 method，记住四条：① 名字 = class 名；② 没有 return type （连 void 都不写）；③ new 的时候自动调用；④ 可以不带参（默认空参版本）也可以带参， 同名不同 signature = overloading。带参 constructor 头部的参数叫 formal parameters（形式参数），调用时传进去的值叫 actual parameters（实际参数）；Java 是 call by value——formal parameter 拿到的是 actual parameter 的副本。 参数与 instance variable 同名时用 this.xxx 指代"正在出生的这个 object"自己的变量。

Movie class 的 constructor 是 Movie(String title, String studio, double rating)。 要构造一部 title = "Lion King"、rating = 8.0 的电影，正确的是？

  • new Movie("Lion King", 8.0)

Actual parameter 的顺序必须严格对齐 formal parameter：String → String → double。 顺序反了（A、C）或参数不够（B），全都过不了编译。

2.3 调用 void method：顺序执行被打断#

无参 non-static method 用 dot operator（点运算符）调用：object.方法名()。 Method 调用会打断顺序执行：控制流跳进 method body，一行行执行完（或遇到 return）， 再回到调用点的下一行继续。理解了这条，"输出顺序"类题目（AP Skill 2.C）就是白送的。

沙盘 D · 执行流：跟着高亮行跳进 method body
main method
Human rin = new Human("Rin"); rin.displayInformation(); Human ken = new Human("Ken"); ken.displayInformation(); System.out.println("done");
displayInformation() 的 method body（Human class 里）
System.out.println(name + " 的信息："); System.out.println(" age = " + age);

点 ▶：看调用栈的 frame 怎么推入（调用）、怎么弹出（执行完回来）
⚠️ 坑点 main 是 static method，它里面不能直接调 instance method——必须先 new 一个 object 再用点运算符。 反过来，class 里各 instance method 之间互调不需要 object，直接写方法名就行（省略了 this.）。

Quiz 2-3-8

Party class 有一个无参 void method cancelParty()；main 里已有 Party myParty = new Party();。合法的调用是？

  • myParty.cancelParty();
  • cancelParty(myParty);
  • myParty.cancelParty(5);
  • Party.myParty.cancelParty();

Non-static method = 用 object 点出来：object.method()。cancelParty(5) 参数数量不匹配（无参 method）。

Quiz 2-3-9

meow() 打印 "Meow "，purr() 打印 "purr "。哪个片段打印 Meow purr？

  • a.meow();
  • a.purr(); a.meow();
  • a.meow(); a.purr();
  • meow(a); purr(a);

Method 按调用顺序一个个执行：meow 先 → "Meow "，purr 后 → "purr "。 D 连调用语法都不对。

同 2-3-8：object + 点 + 方法名 + 括号分号。用 class 名调用（如 Liquid.freeze()）只适用于 static method（§2.5 见）。

2.4 带参的 method 与 overloading#

带参 method 的 signature = 方法名 + 有序的参数 type 列表；调用时 actual parameter 的 顺序和类型都必须匹配。Overloading = 同一个 class 中同名 method、signature 不同， compiler 靠 actual parameter 的 type 自己挑一个。参数名不是 signature 的一部分。

沙盘 C · overloading 调用判定（method 版）
⚠️ 坑点 自问式检查：每个位置各要什么 type，我给了什么 type？ int 塞给 String → incompatible types； double 塞给 int → possible lossy conversion。 报错文案背下来，选择题秒答。

Quiz 2-4-6

square(5) 返回 25、divide(4, 2) 返回 2（都是 int）。这行打印什么？

System.out.println(square(5) + " and " + divide(4, 2));
  • 25 and 2
  • 29 and 2
  • square(5) and divide(4, 2)
  • 27

中间是 String，+ 变成拼接：25 + " and " = "25 and "，再拼 2 = "25 and 2"。 全是数字时 + 才做加法（下一题对比）。

2.5 non-void method · static#

Non-void method 会 return 一个值（int / double / String…），调用时通常要用 variable 接住： int ans = c2.add(5, 5);。至于计数器，先用两个简单问题来区分：是每个对象自己记，还是所有对象共用一份？下面的沙盘会先让你点按钮观察数字，再把行为对应到 Java 术语。

沙盘 E · 两种计数器：对象各自一份 vs 全班共用一份 ⭐
⚠️ 坑点 先看哪个数字变了：c1.count() 改 c1 自己的数字；Cal.count_static() 改 class 上唯一的共享数字。不要把“调用它的对象”误认为“这份数据属于它”。

Quiz 2-5-4

square(2) 返回 int 4、divide(6, 2) 返回 int 3。这行打印什么？

System.out.println(square(2) + divide(6, 2));
  • 4 and 3
  • 7
  • 43
  • 编译错误

两边都是 int 返回值，中间的 + 做加法：4 + 3 = 7。 和 2-4-6 放一起看：有没有 String 参战，+ 的语义完全不同。

Quiz 2-5-5

Method 声明 double calculatePizzaBoxes(int people, double perPerson)。 哪个调用既能编译、又正确接住了 return value？

  • calculatePizzaBoxes(45, 9.0);
  • int result = calculatePizzaBoxes(45, 9.0);
  • double result = calculatePizzaBoxes(9.0, 45);
  • double result = calculatePizzaBoxes(45, 9.0);

B：double 返回值塞进 int → lossy conversion，编译失败。 C：参数顺序反了，45 是 int 不是 double 位置。A 语法上能跑，但 return value 被扔掉了——考试问"正确调用"选 D。

2.6 String Objects · Literals · Concatenation#

String 是 reference type。字面量（如 "Ken"）和 new String("Ken") 都能得到 String；考试中更常见的是字面量。String 是 immutable（不可变）：拼接不会改写旧对象，而是产生新 String；只有把返回的新值赋回变量，变量才会改指向。

Literal
String name = "Ken";：直接用字符串字面量
Constructor
new String("Ken")：构造一个内容相同的 String object
Immutable
concat / + 返回新内容；原 String 不变
Concatenation
遇到 String 后，+ 按从左到右进行字符串拼接
沙盘 F · String 引用与不可变性：逐行执行
⚠️ 坑点 String s = "hi"; s.concat("!"); 不会让 s 变成 "hi!"；要写 s = s.concat("!");。+= 同样会创建并赋回新 String。数字与 String 拼接时要看运算顺序："12" + 4 + 3 是 "1243"，不是 "19"。

Quiz 2-6-5

执行完所有语句后，a 和 b 分别引用什么内容？

String a = "maple"; String b = a; a += (8 + 6) + "!"; b += b.length();
  • a 是 "maple86!"，b 是 "maple5"
  • a 和 b 都是 "maple14!"
  • a 是 "maple14!"，b 是 "maple5"
  • a 是 "maple14!"，b 仍是 "maple"

先算括号内的整数：8 + 6 得 14，所以第一条 += 让 a 指向新字符串 "maple14!"；String 不会被原地修改，b 仍指向原来的 "maple"。最后 b.length() 是 5，因此第二条语句把 b 更新为 "maple5"。

Quiz 2.6 · 算术与字符串拼接

String report = 11 + 7 + ":" + (11 - 7); 执行后，report 的内容是什么？

  • "117:4"
  • "18:4"
  • "18:18"
  • "4:18"

+ 从左到右结合，且遇到 String 前仍执行整数加法：11 + 7 先得 18，再拼接 ":"。括号内先算 11 - 7 = 4，最后得到 "18:4"。

2.7 String Methods · 索引与返回值#

String 的常用方法都通过点运算符调用。索引从 0 开始；charAt(i) 取出位置 i 的字符，substring(from, to) 包含起点但不包含终点，indexOf 找不到时返回 -1。

length() · charAt(i)
字符数；读取一个有效索引上的字符
substring(from, to)
取半开区间 [from, to)；也可只给起点取到末尾
indexOf(text)
返回首次出现位置；没有匹配时返回 -1
equals · compareTo
前者比较内容；后者按字典序返回负数、0 或正数
沙盘 G · String 显微镜：索引、参数与返回值
⚠️ 坑点 "Ken" == new String("Ken") 不保证比较内容相等；比较 String 内容用 equals。charAt 的合法索引是 0 到 length() - 1；越界会抛 StringIndexOutOfBoundsException。compareTo 重点判断结果的正、负或零，不要背示例中的具体差值。

API / package 小抄：String 位于 java.lang，该 package 默认可用，不需要写 import java.lang.String;。AP Quick Reference 也列出 String(String str)、length、两种 substring、indexOf、equals 与 compareTo；对象被打印或与 String 拼接时，会调用它的 toString()。

Quiz 2.7 · charAt

  • e

  • 空字符串

S 的索引为 0，最后一个字符 n 的索引为 5；charAt(6) 才会越界。

"Welcome to Learn Java!".substring(2, 6) 返回什么？

  • Welcome
  • lcom

从索引 2 开始，取到索引 6 之前：索引 2、3、4、5 分别是 l c o m；终点 6 不包含。

2.8 Wrapper Classes · Boxing & Unboxing#

Integer 是 int 的 wrapper，Double 是 double 的 wrapper。Boxing 把 primitive 转成 wrapper object；unboxing 反向取出 primitive。两者既可以显式调用方法，也可以由 Java 自动完成。

沙盘 H · 两条转换轨道：显式步骤 vs 自动步骤
⚠️ 坑点 课件用 new Integer(x) / new Double(x) 展示显式 boxing。新版本 Java 已弃用这些构造器；这里保留它们作为转换示范，实际写新代码更推荐自动装箱或 valueOf。显式 unboxing 的括号不能漏：boxed.intValue()。

Quiz 2.8 · 自动转换

下面两行分别触发什么转换？

Integer boxed = 5; int score = boxed;
  • 两行都是显式 boxing
  • 第一行 auto-unboxing，第二行 autoboxing
  • 第一行 autoboxing，第二行 auto-unboxing
  • 都不涉及转换

5 是 primitive int，赋给 Integer 时自动 boxing；再赋给 int 时自动 unboxing。

Quiz 2.8 · Integer 边界

Integer.MAX_VALUE + 1 以 int 运算时，结果是什么？

  • 抛出 ArithmeticException
  • 2147483648
  • -2147483648
  • 0

int 只保留 32-bit 结果，因此从最大值再加 1 会回绕到 Integer.MIN_VALUE；普通整数溢出不会自动抛出异常。

Quiz 2.8 · Find and Fix

下面哪段代码能正确创建一个代表 5 的 Integer，并打印它的 primitive 值？

  • integer value = 5; System.out.println(value.intValue());
  • Integer value = 5; System.out.println(value.intValue);
  • Integer value = 5; System.out.println(value.intValue());
  • Integer value = 2.3; System.out.println(value.intValue());

class 名区分大小写（Integer），方法调用要带括号（intValue()），而 double 不能直接赋给 Integer。也可以直接自动拆箱：int n = value;。

2.9 Using the Math Class#

Math 是 java.lang 中的工具 class，所用方法都是 static，直接写 Math.method(...)。除了 abs、pow、sqrt 与 random，本课件也演示 min 和 max；这六类都放进下面的可试算面板。

沙盘 I · Math 方法与随机整数区间
⚠️ 坑点 Math.random() 的范围是 [0.0, 1.0)：包含 0，不包含 1。要得到 min 到 max（含两端）的整数，乘以区间格数 max - min + 1，再在转换后加上 min。注意把整个乘积先转成 int。

Quiz 2.9 · min / max

Math.max(10, 7) + Math.min(3, 5) 的结果是什么？

  • 10
  • 13
  • 15
  • 编译错误：Math 不能直接调用

Math.max(10, 7) 是 10，Math.min(3, 5) 是 3；两者都是 static method，直接用 class 名调用，合计 13。

Quiz 2.9 · random 区间

哪段表达式可以生成 3、4、5、6、7，且每个整数都可能出现？

  • (int) Math.random() * 5 + 3
  • (int) (Math.random() * 5) + 3
  • (int) (Math.random() * 4) + 3
  • (int) (Math.random() * 5) + 2

目标区间有 7 - 3 + 1 = 5 个整数。乘 5 得到 [0, 5)，转成 int 后是 0–4，再加 3 得到 3–7。第一项先把小于 1 的随机数转 int，会变成 0。
