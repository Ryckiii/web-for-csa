3.1 Boolean Expressions · 比较与真假#

Boolean expression 的结果只有 true 或 false。关系运算符比较数值： <、>、<=、>=；== 与 != 判断相等或不等。 这些比较可以写在 if 条件里，也可以先存进 boolean variable。

比较大小
<   >   <=   >=
两边是数值或数值表达式
判断相等
==   !=
primitive 比值；reference 比身份
取余数
n % divisor
整除时余数为 0；可用于偶奇和周期
Boolean 结果
boolean valid = score >= 60;
variable 保存 true / false
沙盘 A · Boolean Workbench：输入值，读出真假
⚠️ 坑点 一个 = 是赋值，两个 == 才是比较。Java 的 % 对负数可能给负余数： 判断奇数用 n % 2 != 0，不要用 n % 2 > 0，否则负奇数会被漏掉。

Quiz 3-1-1 · 余数与负数

执行下列代码后，odd 与 positiveRemainder 分别是什么？

int n = -9; boolean odd = n % 2 != 0; boolean positiveRemainder = n % 2 > 0;
  • true、true
  • true、false
  • false、true
  • false、false

Java 中 -9 % 2 的结果是 -1。它不等于 0，所以 odd 为 true；但 -1 > 0 为 false。用“余数非零”判断奇数才能同时覆盖正数和负数。

Quiz 3-1-2 · 关系表达式

a 与 b 的值如下，matches 的值是什么？

int a = 14; int b = 5; boolean matches = a / b == 2 && a % b == 4;
  • true
  • false
  • 2
  • 编译错误：boolean 不能使用 &&

14 / 5 是整数除法，商为 2；14 % 5 的余数为 4。两个比较都为 true，所以 true && true 得 true。

3.2 if Statements · 单向选择#

if 先计算括号里的 Boolean condition：为 true 就执行对应语句块；为 false 就跳过该块，继续运行后面的代码。缩进方便人读，花括号才真正决定哪些语句属于这个分支。

Condition
必须是 Boolean 表达式
为 true
进入 { } 中的代码块
为 false
跳过代码块，不会跳过块之后的语句
顺序执行
多个独立的 if 会分别检查条件
沙盘 B · If Flow Inspector：条件通过了吗？
⚠️ 坑点 不要写 if (condition);：分号会成为空语句，后面的块不再受条件控制。也不要把赋值 = 写进比较条件；例如 if (score = 60) 会因类型不匹配而无法编译。

Quiz 3-2-1 · 单向 if

下面代码输出什么？

int n = 0; if (n < 0) { System.out.print("low "); } System.out.print("ready");
  • low ready
  • ready
  • 什么都不输出
  • low

0 < 0 为 false，因此跳过 low 那行；if 块后面的 print("ready") 不属于该块，仍会执行。

Quiz 3-2-2 · 修正条件

希望仅在 score 大于或等于 60 时打印 Pass。哪段代码正确？

  • if (score >= 60); { System.out.println("Pass"); }
  • if (score = 60) { System.out.println("Pass"); }
  • if (score >= 60) { System.out.println("Pass"); }
  • if (score > 60) { System.out.println("Pass"); }

C 使用比较运算符并包含边界 60。A 虽可编译，但分号结束了 if，块会无条件执行；B 把赋值当比较且类型不匹配；D 漏掉刚好 60 的情况。

3.3 if-else Statements · 双向选择#

当 Boolean condition 为 true 时执行 if 块，否则执行 else 块；同一次执行只会走其中一条路。嵌套 if 可以在已选中的路径里再做一次选择，例如先判断是否为哺乳动物，再决定下一问。

两条路
条件 true → if；条件 false → else
每次只走一条
if/else 两边不会同时执行
嵌套选择
内层条件只在外层进入后才检查
分支之后
离开整个结构后继续顺序执行
沙盘 C · Two-Way Branch：沿条件树走一遍
⚠️ 坑点 花括号是追踪嵌套结构的可靠边界。先标出外层分支，再进入其中的内层 if；不要只凭缩进猜测哪一个 else 属于哪一个 if。

Quiz 3-3-1 · 嵌套 if

下列代码会输出什么？

boolean mammal = false; boolean pet = true; if (mammal) { if (pet) System.out.println("dog"); else System.out.println("elephant"); } else System.out.println("bird");
  • dog
  • elephant
  • bird
  • bird 后接 dog

外层 mammal 为 false，直接走外层 else 输出 bird。内层的 pet 条件根本不会被检查。

3.4 else-if Statements · 多路分支#

if / else if / else 用于多路选择：从上向下检查，执行第一个为真的分支后，整条链就结束。条件顺序因此很重要；把多个独立 if 改成 else-if，常常正是修复“后面的赋值覆盖前面结果”的关键。

从上往下检查
逐一求值条件
首个 true 即停
后续 else-if 不再执行
else 可兜底
之前条件全为 false 才会走到
独立 if 不同
多个 if 可以依次执行并覆写状态
沙盘 D · Branch Ladder：同一个分数，两种写法
⚠️ 坑点 若按分数从高到低分档，使用有序的 else-if 链。多个独立 if 可能不断改写同一个变量；尤其要看 else 配对的是哪一个 if。

Quiz 3-4-1 · 首个为真的分支

x 为 0 时，输出什么？

if (x < 0) System.out.println("negative"); else if (x <= 0) System.out.println("zero"); else System.out.println("positive");
  • negative
  • zero
  • positive
  • 没有输出

第一项 0 < 0 为 false；第二项 0 <= 0 为 true，于是输出 zero，链条随即结束。

Quiz 3-4-2 · 独立 if 会覆写

下面的独立 if 代码最终打印什么？

int score = 86; String grade = "?"; if (score >= 90) grade = "A"; if (score >= 80) grade = "B"; if (score >= 70) grade = "C"; if (score >= 60) grade = "D"; else grade = "F"; System.out.println(grade);
  • A
  • B
  • C
  • D

分数 86 让第二、第三、第四个 if 都为 true，grade 依次被改成 B、C、D。最后一个 if 的 else 只在 score < 60 时执行；因此最终打印 D。改成 else-if 链才会保留首个匹配的 B。

3.5 Compound Boolean Expressions · 复合条件#

用 ! 取反、&& 表示“且”、|| 表示“或”，可以把条件组合起来。优先级是 ! 高于 &&，&& 高于 ||；括号优先级最高。&& 与 || 还会进行 short-circuit evaluation（短路求值）。

!P
反转 true / false
P && Q
两边都 true 才是 true
P || Q
至少一边 true 就是 true
优先级
! → && → ||；必要时加括号
沙盘 E · Logic & Short-Circuit Lab
⚠️ 坑点 false && rhs 会跳过 rhs；true || rhs 也会跳过 rhs。只有左侧不足以决定结果时，Java 才会计算右侧。顺序写反，可能让本来可避免的除零或 null 调用发生。

Quiz 3-5-1 · 优先级

表达式 !a || b && !c 的结果是什么？

boolean a = true; boolean b = false; boolean c = false; boolean result = !a || b && !c;
  • true
  • false
  • 编译错误：必须给每个运算加括号
  • 结果取决于短路是否执行

! 先算：!a 为 false、!c 为 true；再算 b && !c，即 false；最后 false || false 为 false。短路不会改变逻辑结果。

Quiz 3-5-2 · && 短路

当 x 为 0、y 为 7 时，下面代码会发生什么？

if (x > 0 && y / x > 2) System.out.println("yes"); else System.out.println("safe");
  • 打印 yes
  • 打印 safe，不会除以 0
  • 抛出 ArithmeticException
  • 打印 yes 和 safe

左侧 x > 0 为 false，&& 已能确定整个条件为 false，于是跳过 y / x。执行 else，打印 safe。

Quiz 3-5-3 · || 的求值边界

当 x 为 0、y 为 7 时，下面代码会发生什么？

if (x > 0 || y / x > 2) System.out.println("yes"); else System.out.println("no");
  • 打印 yes
  • 打印 no
  • 抛出 ArithmeticException，右侧会执行
  • 右侧被短路，什么都不发生

左侧 x > 0 为 false；对 || 而言，这还不能确定最终结果，所以 Java 会计算右侧。y / 0 导致运行时 ArithmeticException。

3.6 Equivalent Boolean Expressions · 等价变形#

两个 Boolean expressions 若对所有可能输入都得到相同结果，就是等价表达式。De Morgan’s Laws 提供两条常用改写：把 NOT 推进括号时，&& 与 || 互换，且每个项都要取反。否定关系表达式时，比较符也要翻转。

!(A && B)
等价于 !A || !B
!(A || B)
等价于 !A && !B
!(x < y)
等价于 x >= y
!(x <= y)
等价于 x > y
沙盘 F · Equivalence Checker：逐行跑完真值表
⚠️ 坑点 NOT 推入括号时要同时做两件事：每个 Boolean term 取反，并把 AND / OR 互换。关系符取反也要包含边界：!(x <= y) 是 x > y，不是 x >= y。

Quiz 3-6-1 · De Morgan

!(a || b) 等价于哪一个表达式？

  • !a || !b
  • !a && !b
  • a && b
  • a || b

取反推进 OR 括号后，运算符换成 AND，且两项各自取反：!(a || b) == !a && !b。

Quiz 3-6-2 · 关系运算符取反

!(x <= y) 与哪一个表达式完全等价？

  • x >= y
  • x < y
  • x > y
  • x == y

x <= y 包含小于或相等；其否定必须同时排除这两种情况，所以只剩 x > y。

3.7 Comparing Objects · 身份、内容与 null#

对 primitive，== 比数值；对 reference，== 比两个变量是否指向同一个 object。String 内容是否相同，用 .equals()。引用变量还可能是 null，此时调用方法会触发 NullPointerException。

Reference identity
s1 == s2：是否同一个 object
String value
s1.equals(s2)：字符内容是否相同
Alias
s3 = s1 后两个变量指向同一个 object
null guard
先判 s != null，再调用 s.method()
沙盘 G · Reference & Value：箭头相同，内容也可能相同
⚠️ 坑点 相同 String 字面量可能因 string pool 而共享引用，但这不等于应该用 == 比较文字。考内容相等就用 .equals()。调用 s.equals(...) 前也要确认 s 不是 null。

Quiz 3-7-1 · Alias 与 equals

执行完代码后，哪一个 Boolean expression 为 true？

String s1 = new String("map"); String s2 = new String("map"); String s3 = s1;
  • s1 == s2
  • !s1.equals(s2)
  • s1 != s2 && s1.equals(s2) && s1 == s3
  • s2 == s3

s1 与 s2 是两个独立 new 出来的 object，所以 s1 != s2；内容相同，s1.equals(s2) 为 true。s3 = s1 是 alias，因此 s1 == s3 为 true。

Quiz 3-7-2 · null 安全

s 为 null。下列代码的结果是什么？

if (s != null && s.indexOf("a") >= 0) { System.out.println("contains a"); }
  • 打印 contains a
  • 不抛异常，也不打印
  • 抛出 NullPointerException
  • 编译错误：String 不能与 null 比较

左侧 s != null 为 false，&& 短路跳过右侧的 s.indexOf("a")，所以安全地不进入代码块。若先调用方法再判断 null，就会抛 NullPointerException。

Quiz 3-12-4 · Short-circuit 综合题

x = 0、y = 9 时，执行下面代码会发生什么？

if (x > 0 || y / x == 3) System.out.println("first case"); else System.out.println("second case");
  • 打印 first case
  • 打印 second case
  • 求值右侧时抛出 ArithmeticException
  • 右侧被短路，所以不报错

对 ||，左侧只有为 true 才能短路。x > 0 为 false，因此会计算 y / x；整数除以 0 在运行时抛出 ArithmeticException。

Quiz 3-12-5 · 等价表达式

!(c || d) 与哪个表达式对所有 Boolean 输入都等价？

  • !c || !d
  • !c && !d
  • c && d
  • c || d

由 De Morgan’s Law，否定 OR 等价于两个否定项的 AND：!(c || d) == !c && !d。其他选项至少在一组输入下结果不同。

Quiz 3-12-8 · 选出所有正确代码段

学校按下列标准给分：93 及以上为 A，84–92 为 B，75–83 为 C，低于 75 为 F。哪些代码段能对任意整数 score 正确设置 grade？

// I if (score >= 93) grade = "A"; if (score >= 84 && score < 93) grade = "B"; if (score >= 75 && score < 84) grade = "C"; if (score < 75) grade = "F"; // II if (score >= 93) grade = "A"; if (score >= 84) grade = "B"; if (score >= 75) grade = "C"; if (score < 75) grade = "F"; // III if (score >= 93) grade = "A"; else if (score >= 84) grade = "B"; else if (score >= 75) grade = "C"; else grade = "F";
  • Code segment I
  • Code segment II
  • Code segment III

I 的各区间互斥，只有对应区间会赋值；III 是依序选择，首个真分支结束。II 对高分会被后续 if 覆写，例如 95 会依次变成 A、B、C，因此不正确。选出所有正确项：I 和 III。

Quiz 3-12-10 · 顺序执行

执行完下列代码后，输出是什么？

int x = 3; int y = 2; if (x > 2) x += 5; if (y > 1) y++; if (x > 2) System.out.print("first "); if (y < 3) System.out.print("second "); System.out.print("third");
  • first
  • first second
  • first third
  • second third

x 变成 8，y 变成 3。于是第一个输出条件为 true，第二个 y < 3 为 false，最后一行不受 if 控制仍会输出 third。

Quiz 3-12-11 · 整数除法与 if

x = 3、y = 2 时，输出是什么？

if (y / x > 0) System.out.print("first "); System.out.print("second");
  • first second
  • second
  • 什么都不输出
  • 抛出 ArithmeticException

y 与 x 都是 int，2 / 3 的整数结果为 0，因此条件 0 > 0 为 false。第一句被跳过，但 if 后的第二句仍会打印 second。
